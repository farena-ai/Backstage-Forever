# Optional character snapshot addon

Use Set up my companion in the desktop app to prepare and verify this addon's three owned files automatically. Enable Backstage Forever in WoW. The Interface 16001 loader declaration matches inspected Forever client configuration; runtime guards handle unavailable or restricted APIs. Synthetic Lua tests do not certify actual in-client loading. See [Compatibility](../../docs/COMPATIBILITY.md).

Visit the characters you want imported. **Levelled up or changed areas? Type `/reload` in WoW to refresh your companion.** Logout also saves. The desktop automatically reads the resulting saved snapshot; it cannot see continuous live changes before WoW writes them to disk. No input automation, memory access, combat calculation or forced reload is used. Manual desktop profiles remain available without this addon.

The optional native Adventure Compass shows permitted current out-of-combat character, quest and XP information, recent observed turn-ins and game-provided destinations. Drag its title to move; use the - button to collapse and X to hide. Type `/bf show` to reopen it. Use `/bf hide`, `/bf show` or `/bf status`. It hides during combat. If a public API is unavailable or restricted, the corresponding detail is omitted. This is an observed window, not a complete historical quest guide.
