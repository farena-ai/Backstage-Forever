# Experimental addon

This is an unverified manual-copy prototype, not an install-ready certified addon. Follow [the compatibility instructions](../../docs/COMPATIBILITY.md) to collect the intended client's fourth `GetBuildInfo()` return and prepare a separate local test copy. The `.toc.template` deliberately refuses to guess an interface number.

The desktop already works with manually entered profiles. This panel does not import or synchronize data. No in-client API or combat behavior test has been completed. Nothing has been installed into game files.
