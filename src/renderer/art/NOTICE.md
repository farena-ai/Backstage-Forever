# Backstage Forever art

Original artwork made for Backstage Forever by Backstage Coding (art pass 1, 0.21.0). It was generated locally with ComfyUI using the Qwen-Image 2.1 model (Apache-2.0), then cropped, masked and compressed by hand.

None of these images is taken from World of Warcraft or any Blizzard product, and none reproduces Blizzard characters, logos or landmarks.

| File | Used on |
|---|---|
| `hero-now.webp` | Now page header |
| `hero-help.webp` | Help → Commands and Field guide headers |
| `badge-level.webp` | Level-up celebration crest |
| `icons/*.png` | Commands group crests |
| `steps/*.png` | Now "Do this next" step crests (art pass 2, 0.22.0) |
| `classes/*.png` | Class crests on Now and the talent coach (0.23.0) |
| `zones/*.webp` | Now "Where to level" landscape vistas, one per kind of zone (art pass 2, 0.22.0); city banners `warcamp` and `citadel` (0.26.0) |
| `pins/*.png` | World Map pin medallions, one per pin kind (0.26.0) |
