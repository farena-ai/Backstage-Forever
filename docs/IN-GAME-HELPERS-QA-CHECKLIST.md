# In-Game Helpers QA — local only

QA.3 is the corrected successor to QA.2 (`875dcbb`, `1.16.902`), which is held for a stale desktop draft during follow-game switches. QA.3 adds the desktop ownership correction and regression, not new addon behavior. The addon TOC, capture marker and desktop source all use numeric `1.16.903`; this is not a release identifier. The ZIP is addon-only; use the matching local desktop source to exercise the correction. No update feed, desktop installer, signing or publishing is part of this candidate.

The delta excludes post-stable Companion/Workshop work, DPS coaching, starter/triage views, new general Compass presets/mute, and unrelated route data. The existing Compass collapse and baseline junk-sale protections remain.

## Manual live checks

On QA.3 the owner reported passing the native panel, short batch, combat rejection, `/reload` and alt persistence, plus Adventure Compass tracking and the conditional nearby review check. This does not establish exact client build/locale, all review availability branches, the longest paste, broader gameplay checks, or rollback. The table below remains the full repeatable checklist, not a list of passed checks.

Use a disposable WoW Forever installation/profile. Back up that **test** profile’s addon folder and account/per-character SavedVariables with the client stopped; record the exact original TOC version for rollback. Record the exact build, locale, test character, ZIP SHA-256 and outcome per row. Extract the ZIP into the disposable client’s `Interface/AddOns`; verify that the client loads `BackstageForever` version `1.16.903`. Start with the desktop closed. A missing API/data shape is a blocked row, not a pass. Do not use a real account’s valuables for merchant/reward tests.

| Check | Steps and expected result |
| --- | --- |
| Native preferences | Open `/bf helpers panel` in English and German; check all 11 labels fit. Disable `questTracker` with a checkbox, query `/bf helpers questTracker`, `/reload`, and query again. Verify a fresh alt defaults on and returning to the first character preserves explicit off. Test with desktop still closed. |
| Compass | Watch a quest with visible unfinished counts; verify title and counts. Try `/bf compass track QuestID`, `/bf compass missing`, then `/bf compass track clear`. A missing current-map marker must not offer a waypoint. Use `/bf compass review` beside a ready local hand-in; it is independent of the tracker. On `1.60.1.70888`, browse a noninitial route step before taking the offered local detour. Acceptance must not place a waypoint; click the waypoint explicitly. Cancel once; then repeat and turn in the exact quest. Verify the browsed step resumes or the route advances only for real route progress. Recheck after a map transition and combat. |
| Objective hints and vendor | On `1.60.1.70862` or `1.60.1.70888`, verify a reviewed watched objective on the correct target; a lookalike or completed objective must not produce a hint. For Lazy Peons, treat “sleeping” as a condition to check yourself. At a vendor with disposable items, confirm preview excludes protected or unreadable-status items and protection remains with optional hints off. Never authorize a sale merely to clear the check. |
| Gathering | On `1.60.1.70862`, manually gather a supported node; verify the map shows an approximate last-seen spot, not a live spawn. Switch map or character and check the spot does not follow. Toggle the helper off/on. |
| Quest rewards | Check a real reward choice with known stats and usability, then a mixed or uncached comparison. Only qualifying evidence should glow, and no reward should be selected or equipped by the addon. Close/reopen the same quest and toggle off while item data may still load; an old callback must not repaint. Prior gear opt-out still wins. |
| Spell rank | On `1.60.1.70959` with a Mage who knows Frostbolt ranks 3 and 4, place rank 3 in a real spell action slot. Verify the narrow reminder; replace it manually and verify no stale recommendation. An unlearned rank, wrong build, wrong action kind or combat must not produce a new reminder. No automatic casting, equipment or rebinding. |
| Desktop handoff | In isolated desktop Settings → Game connection → In-Game Helpers → Prepare changes for WoW, use the keyboard to set Quest tracker off and Objective hints on; leave the rest unchanged. Select the preview and copy it yourself. Verify the literal `/bf helpers apply questTracker=off objectiveHints=on commit` and the warning that the logged-in character, not the desktop selection, is the target. Switching desktop characters should discard the outgoing draft. Help → Commands should list the batch alongside the standalone commands. The desktop must neither apply nor claim to apply the preferences. |
| Live batch | On the intended disposable character, set known starting values with the native panel. In English and German, manually paste the complete line out of combat and verify the local confirmation and native checkboxes; the untouched preferences must stay put. Try the longest all-11-helper preview to check real chat length. Omit `commit` and try a valid prefix followed by an invalid assignment; verify no partial changes. Try a valid command in combat; verify rejection and retry after combat. `/reload` and check that explicit off survives, switch to a fresh alt and verify defaults, then return and check the original character again. |

With follow-game enabled, select a draft command and leave it focused. Import a newer save from another disposable character; the outgoing draft should disappear when the desktop observes the new owner. Return to the first character and verify its old choices do not reappear. This cannot recall text already copied or detect a switch the desktop has not observed. Always verify the intended character in WoW before pasting.

Rollback only in the test environment: close WoW, remove the candidate addon folder, restore the backed-up addon and account/per-character test SavedVariables, and reopen WoW. Confirm the exact recorded original version loads (not `1.16.903`). Verify the restored character preferences with the original commands. Do not use the QA ZIP as a production upgrade.
