# Your hands-on check before 1.0

Backstage Forever 0.12 is the checkpoint requested by Frank Arena before deciding on 1.0 release quality. These are player-led checks, not claims established by automated fixtures. Keep 1.0 unreleased until this review and any fixes are complete.

## Update and characters

- [ ] Confirm the installed app says 0.12.3 and opens normally with existing profiles, notes, plans and provider connections.
- [ ] Let BF prepare/verify its companion files. Load the updated addon on the next game launch, or use one voluntary /reload if the addon was already installed and WoW is running.
- [ ] Visit two characters with the addon enabled and let the game save naturally. Confirm their identity, faction, level, quests and private journals stay separate. Never-visited alts are not promised.
- [ ] Switch the desktop character deliberately, confirm following pauses, then resume following and check the selected saved character. Inside WoW the Compass must always describe the currently played character.
- [ ] Drag, collapse, hide and reopen the Compass with /bf show. Check combat hiding and recovery. Native guidance should not require routine reloads after objectives or levels.

## Director and preparation

- [ ] Check the primary action and alternatives against actual quest state. Reasons, saved timestamps and reference qualifiers should make sense; a ready quest must not be called turned in.
- [ ] Start a quest session, check the resulting tracked plan and confirm another identical click reuses it. Save newer real quest progress and check observed completion versus manual checks.
- [ ] Open your profession normally in game if recipe observations are unavailable. After a natural save, compare owned profession/rank, a known recipe and its reagent quantities with Preparation.
- [ ] Compare carried material counts with the backpack and four bags. Partial/unavailable observations must not claim a zero shortfall or full account inventory. Bank/account storage and transfer availability are not promised.
- [ ] Change recipe/craft count and verify the shopping calculation. Confirm its generated Company steps are manual checks, not invented game completion evidence. Review low-bag-space behavior as space changes.

## Optional voice and memory

- [ ] Enable/use voice deliberately; confirm visible listening status and that release/Stop/cancel, navigation and character changes stop recording. Verify microphone permission failures leave typed questions usable.
- [ ] Review recognition quality with your character/race/quest names. Dictation alone must not send an AI request; review the editable text and explicitly Send.
- [ ] Request local answer reading, interrupt it, then start dictation. The app must stop its own speech first. Confirm no audio file is retained.
- [ ] Save an exchange locally only when wanted. Check character isolation, review/delete and the separate explicit control for including selected memories in a future question. Notes/goals/journeys must remain excluded unless deliberately typed into the question.

## Party plans and Quest Guide

- [ ] Preview an export before saving/sharing it. It should contain the selected plan's disclosed text, not provider secrets, private journals, captured IDs or local paths. Treat your own deliberately included text as shareable.
- [ ] Import a sample plan without replacing existing records. Imported steps should have new local IDs, be unassigned/manual and carry no observed completion proof. No message or game action should be sent automatically.
- [ ] Compare several ready and unfinished quest destinations with the game. Saved game, approximate reference and clue labels must remain distinct. Copy a supported waypoint and paste it yourself; verify phase/build handling and missing-point messages.
- [ ] Check Quest Guide visually alongside the other pages, including narrow windows, both factions, native dropdowns, empty data and error states.

## Release-quality decision

- [ ] Try Windows scaling at your usual setting and keyboard/reduced-motion operation. Note unreadable, clipped or hard-to-reach controls and distracting animation or idle load.
- [ ] Report actual unsupported APIs, wrong quest/recipe facts, voice failures, setup friction or update failures. Preserve the relevant public source/build information; do not send credentials or a full private backup publicly.
- [ ] Review remaining work for clean-machine install/update recovery, accessibility, publisher signing and documented content coverage before authorizing a 1.0 release.

Local deterministic features work without AI. An explicitly sent AI question uses the chosen connection and its access/billing terms. Native observations and the desktop's saved-file boundary remain different; refreshing BF cannot force WoW to save.
