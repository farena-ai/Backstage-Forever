# J31 raid boss tip review — Molten Core

This batch is **Classic reference**, not confirmed Forever encounter behavior. ForeverDB lists these encounters under Molten Core but labels its encounter advice Classic data and notes that Forever mechanics may change.[3] The Classic creature IDs match the Classic NPC links in the Molten Core guide and the CMaNGOS Classic DB 1.12.1 dump; they are not observations from the Forever client.[4][5]

| Boss (Classic creature ID) | Cross-checked advice |
| --- | --- |
| Lucifron (`12118`) | Impending Doom is a magic dispel; Lucifron's Curse needs curse removal. These are separate debuffs.[1][2][3] |
| Magmadar (`11982`) | Hunters can remove Frenzy with Tranquilizing Shot; prepare for the fear on the tank.[1][2][3] |
| Gehennas (`12259`) | Leave Rain of Fire and remove the healing-reduction curse.[1][2][3] |
| Garr (`12057`) | Banish or tank Firesworn; keep clear when they die and explode. The tip does not prescribe add order, distance, or count.[1][2][3] |

The same short text is used by the Instance Atlas, Companion and addon. For this batch the addon requires a matching English target name and creature ID in the expected raid instance (`409`). Unknown or unavailable identity fails closed. The feature displays text only; it does not time, announce, or act on mechanics, and does not write encounter history. Existing dungeon, Onyxia and Ragnaros tips are unchanged. Other raid encounters remain outside this review. Live Forever validation has not been performed.
