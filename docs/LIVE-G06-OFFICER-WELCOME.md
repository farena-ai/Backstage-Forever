# LIVE-G06 · Officer decisions and public welcome copy (W7 7B)

In **Plans → Party → Guild Run Pack**, open a saved **Organized** run. The private officer log and the public welcome editor are separate actions. Neither uses the next-run handoff (7A).

- **Private officer log:** Record a manual decision with a local recorder label and optional private reason or trial note. Correct the current entry in a chain by recording a replacement and the reason for correcting it. The original actor label, timestamp and wording remain visible. There is no edit/delete action or silent eviction; each run holds at most 64 entries including corrections. A cancelled run keeps readable history but accepts no new entries. Recorder labels are self-reported, not authenticated officer identities; this is private to the local installation, not a multi-user permissions system. The log never infers attendance or membership, ranks members, awards loot, or promotes anyone.
- **Public welcome copy:** Start with empty fields for guild name, welcome message, optional recruiting needs and optional public contact. Review the exact plain text before exporting it to a file. No event, roster, officer or journal fields are carried into it. Manually entered public wording is retained as reviewed, so do not type private information there. Editing requires a new review. Nothing is posted or sent automatically.

The log uses the same locally authored event ID as the organizer board, but has its own app-owned file. Run revisions retain the history; receipt of a pack with the same ID does not grant access. The log is not in either Run Pack format or a journal backup. Replacing the journal retires existing action tokens without erasing installation-owned runs or decisions. Full local reset removes the committed log and its interrupted atomic writes. A downgrade to a version unaware of the log can leave its file on disk after reset; re-importing a portable Run Pack cannot reattach that log because import only creates a received record. Existing exported files remain outside app reset.

Verification: `node --test tests/guild-run-desktop.test.cjs tests/guild-run-pack.test.cjs` exercises the IPC and storage contracts. `npm run test:guild-run` uses synthetic Electron profiles to record and correct a decision, review and manually export separate welcome text, compare exact Run Pack and backup bytes, hold an export through a same-profile journal replacement, reopen history across restart, and check cancel/confirmed reset cleanup.
