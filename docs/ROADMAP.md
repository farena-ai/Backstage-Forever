# Build roadmap

## 0.3.0 — implemented preview work

- Optional guarded addon installation and five-second saved-file synchronization. Reload/logout snapshots, visible freshness, stable roster merge and retained notes/goals; last-played following defaults on and deliberate selection pauses it.
- Provider/auth-specific model catalogs, friendly selection and manual entry, separate Ollama Cloud native chat, no inference entitlement probes and no silent fallback.
- Permanent WoW Forever specialist policy, local heuristic off-topic gate and visible public character context, enabled by default with persistent opt-out. No autonomous paid background inference.
- Graphical roster and planning cards. Nine original class portraits and Alliance/Horde environments are included; neutral fallback remains. Art does not represent an actual captured player portrait.
- Existing local profiles/backups, private credentials, original environment artwork and authenticated automatic Windows updates remain supported.

## Next: acceptance in the real environment

1. Verify addon loading and public APIs in the actual Forever client, then level/zone updates, `/reload` and logout exports, switching characters/accounts and stale/partial-file recovery. The bridge is saved snapshots, not fake realtime.
2. Exercise real ChatGPT and Claude consent, model catalogs, prompts, refresh/logout/reset, cancellation and limits with authorized accounts. API catalogs and Claude initialization are not plan-entitlement certificates.
3. Complete graphical assets and review beginner flows, keyboard navigation, screen-reader use and reduced motion.
4. Verify clean Windows install/upgrade/uninstall and actual self-update with data preservation. Add Authenticode when a publisher certificate is configured; Ed25519 update integrity already exists.

## Later, only with supported APIs and evidence

Quest, gear and progress planning may expand only around supported APIs and verified data. Do not invent current equipment, completed quests or a realtime channel. General planning suggestions remain labeled suggestions.

Grok subscription requires a verified isolated official route, private credential lifecycle, no tools/hooks/game execution and no API fallback before enablement. Other possible work includes intentional friend sharing and optional voice.

No combat computation, automated play, credential sharing, unsupported live bridge or release watcher jobs. Public GitHub preview releases are not store beta/testing submissions. See [Validation](VALIDATION.md) for evidence and remaining gates.
