# Forever Companion accuracy

The Companion has two failures to address. A travel question can confuse natural phrasing with the place name, and a provider can paraphrase a good local answer into a bad one. Adding a single stock answer would leave both failures in place. Sending every gap to a provider would widen apparent coverage without improving evidence.

Normalize transport instructions separately from place names. Keep the caller's preferred mode through follow-ups. Add independently sourced walking directions to the existing checked Forever travel reference, with route directions and approximate landmarks tied to their sources. Keep uncovered directions explicit and useful.

Use local facts directly for straightforward questions when the existing resolver has a factual answer. Preserve model assistance for open-ended advice and roleplay. Exercise the service with the reported question and a mixed set of practical questions covering quests, items, trainers, transport and source gaps.
