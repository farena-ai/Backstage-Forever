# Cinematic desktop and authenticated automatic updates

## Goals
The owner requests automatic checks/updates, a dramatic increase in fantasy art quality, a concrete Grok OAuth explanation and the next build priorities. Ship 0.2.0 with an original painterly fantasy identity and a real authenticated Windows update path. Preserve local profiles, privacy defaults and provider behavior.

## Decisions and alternatives
Use an app-owned Ed25519-signed release manifest, bounded HTTPS downloads, installer SHA256 verification and a pinned public key. Current installers lack Authenticode certificates, so unsigned GitHub metadata alone cannot authorize execution. A conventional electron-updater deployment with Authenticode remains a future option when a publisher certificate exists; a manual-only flow no longer meets the requested behavior. Private signing material is never shipped or committed; generate/store it with Windows DPAPI and configure a repository release secret through stdin. Source builds do not perform automatic network checks or install updates.

Installed apps check after startup and every six hours while running, download authenticated newer releases, and install on normal app exit. They offer Check now, Restart and update, automatic-check preference and install-on-exit preference. No forced mid-session restart, background service, OS scheduled task, cron, automation/chat watcher or silent API billing change. First upgrade from 0.1.0 requires a one-time manual install because that version contains no updater.

## Update protocol
GitHub repository is fixed to farena-ai/Backstage-Forever. Query published releases (including this app's preview releases) and accept only strict vMAJOR.MINOR.PATCH tags with a matching backstage-update.json asset URL. Envelope is {payload:base64,signature:base64}; payload is exact UTF8 JSON bytes signed with Ed25519, {schemaVersion:1,version,releaseTag,url,sha256,size,publishedAt}. Version/tag/filename/URL are mutually consistent and fixed to the same repository/release. Reject unsigned/tampered/malformed manifests, unknown keys, same/older versions, oversized files and redirects outside GitHub's documented asset hosts. Hash and length must match both after download and immediately before execution. Cache writes are atomic, cache paths app-owned, failed transfers never become installers. A new signed version replaces an older queued version only after verification. Reject links/symlinks outside the app-owned cache. No remote commands or arbitrary executable URLs.

Main owns the updater and native installer spawn with fixed arguments, no shell. Validate IPC sender through the existing boundary. A release workflow on explicit version tags tests/builds/signs assets using a protected repository secret and publishes versioned releases. Local signing script accepts a key via environment or protected local signing helper, never command-line key text. Installer remains visibly unsigned to Windows until Authenticode is configured; application update signatures provide a separate trust mechanism.

## Public interfaces
Bridge adds updateStatus(), checkForUpdates(), setUpdatePreferences({automatic:boolean,installOnQuit:boolean}), installUpdate(). Sanitized status: {phase,currentVersion,availableVersion,automatic,installOnQuit,progress,lastChecked,message}; phase is disabled/idle/checking/downloading/ready/error/current/unsupported. No executable paths or private key data in renderer. Preferences/cache live separately under userData/updates; reset cancels work and clears app-owned update files. Existing profile schema/backups remain compatible.

## Grok and next scope
OAuth itself is implemented by the official Grok CLI. The unresolved work is an isolated inference invocation or a supported direct OAuth inference client, followed by own-home credential lifecycle, no billing fallback, malicious prompt/no-tool tests, cancellation/logout/reset tests, and user-led live sign-in. Do not claim that OAuth is impossible or enable general system/game tools. Next after this release: live ChatGPT/Claude acceptance and model discovery; safe Grok adapter; verified manual addon-data import; clean-machine/upgrade/uninstall and signing; then verified game-data planning and optional voice.
