# Now quest flow design

Rank actionable stops from BF's existing game observations and reviewed references. Now, spoken steps and Mini Now use the same ordering. Same-zone distance, pinned quests and destination evidence influence the ranking. A plain reason accompanies the chosen action.

The player starts a two- or three-stop loop from Now. The loop contains compatible, located quests in the current zone. BF advances on positive quest evidence and preserves the remaining route during temporary signal loss. The desktop map shows the stops together and lets the player inspect a destination. The player can end the loop from Now. Loops belong to the selected character and current desktop session.

The map carries the same evidence label as Now, including inferred quest givers and missing locations. Missing-location reports open a prefilled Desk draft for review. The draft contains only the chosen quest ID, zone and build. Admin support groups repeated reports for review.

Mini Now puts the current action, destination and source first. Details and alternatives open on demand. The existing painted map and parchment treatment carry the new controls.
