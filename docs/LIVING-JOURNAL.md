# Living field journal

This is the layout and live-character follow-on to the 1.7.0 art release. Keep each page useful before making it more ornate. Preserve existing game and reference semantics, localization, keyboard access, installed map and item art, and support for Horde and Alliance. Do not change the user's game installation during verification.

| Workspace | Design target | Verify with |
|---|---|---|
| Now | Next action first. The active character and meaningful progress tell the story; setup remains accessible without taking over the page. | Fresh, disconnected, saved and live states; compare what fits before scrolling. |
| World Map | Keep the map central and group layers by the task a player is doing, with the result next to the map. | Find a trainer, follow a quest result, switch gathering and service layers. |
| Ledger | Tables first, closely grouped filters, and consistent numeric alignment. Show charts only when real observations make a comparison worth seeing. | Compare the same item across characters, find quantities, scan prices, exercise empty and populated results. |
| Instance Atlas | Recognizable illustrated entries with level, location and loot signals to scan. Move verbose preparation into the expanded entry without removing quest or map actions. | Compare options, expand one entry, open linked quests and loot. |
| Character identity | Original portraits keyed by known race, class and male/female game-model selection, with faction styling. Use an honest fallback when data is missing. Never present preset artwork as the player's exact face or equipped gear. | Verify both factions, race variants, each supported class/model and unknown metadata. |

Follow-on pass: Companion hierarchy and the remaining shared controls; character and reference workspaces using the same patterns. Use real progress or history only. Show units and scope, preserve exact values, and omit charts when observations are missing. Use live state only where the existing connection can supply it. Suppress decorative motion under reduced-motion settings. Review native desktop fixtures in English and compact German, and distinguish synthetic live-link evidence from a live WoW client check.
