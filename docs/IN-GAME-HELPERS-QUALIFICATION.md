## Desktop batch handoff — direct apply held

- `src/core/live-bridge.cjs` samples and decodes a strip drawn by the addon. It has no desktop-to-addon write or acknowledgement path. The Ask panel displays desktop replies in an Electron window; the addon does not receive those replies. Game connection installs addon resources and reads SavedVariables; it does not provide a supported, per-character runtime setter. Writing the save from desktop would race the running game and could be overwritten at logout; injected input and addon-code/config rewrites are not supported control paths.
- **Settings → Game connection → In-Game Helpers → Prepare changes for WoW** drafts a sparse batch for the selected desktop character. “Leave unchanged” neither reads nor writes the native value. The draft stays in the view and is discarded when switching characters. Select the preview and copy it yourself. Confirm the logged-in character, paste the whole line in WoW chat outside combat with the updated addon, and read its reply. The command contains no character data and cannot verify that the desktop and game selections match. For desktop-independent control, use `/bf helpers panel` or the existing per-key commands.
- Example: `/bf helpers apply questTracker=off objectiveHints=on commit`. The final `commit` token prevents a truncated paste from applying a partial batch. The addon validates the complete allow-listed batch before recording explicit preferences, synchronizes native checkboxes, and confirms the values locally. No new transport, game-file writes from desktop, input simulation, clipboard writes from the app, or sharing changes. Baseline quest-item sale protection is independent of helper choices.
- On the develop integration, 366 focused Node/Fengari checks passed, along with locale reproduction and both Electron smokes. This is not a receipt for the stable-based QA successor. The helper smoke uses synthetic characters, holds the real picker save, checks a German compact keyboard handoff, and verifies that drafting leaves journal bytes, renderer storage and clipboard untouched.
- For a future direct control, require a supported runtime receiver with exact session/character identity and a matching addon acknowledgement after applying the allow-listed changes; do not infer either from the strip or from the currently selected desktop profile. See the [QA checklist](IN-GAME-HELPERS-QA-CHECKLIST.md) for the limited owner-reported QA.3 results and outstanding live checks. Automated checks do not qualify the live client's chat length or API availability.
