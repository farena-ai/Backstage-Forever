# Backstage Forever 1.10.0 — All-in-One

**Local candidate; not published.** Changes since v1.9.0:

- **Pick up where you left off.** Now shows one next action and why it was suggested; the in-game Adventure Compass keeps recommendations quieter. Desktop Quiet, Leveling, and Workshop presets preview changes before applying them. Addon setup gives specific recovery steps and supports a clean retry.
- **Recover a route.** Desktop Guided Route supports resuming, skipping without granting completion, and opening a matching map target when evidence allows it. Character switches, deletion, and local reset clear the appropriate route or recommendation state. The Dwarf/Gnome opening and Horde Desolace reviews record exclusions; this is not a new or verified 1–60 route.
- **Prepare from saved evidence.** Workshop separates carried shortfalls from last-seen storage and conditional purchase estimates. Ledger shows saved carried materials for supported reputation turn-ins. These are not live stock, prices or purchase instructions.
- **Review your dungeons and gear.** Instance Atlas links supported loot to the same item in Character Sheet and distinguishes observed ownership from reference information. Journey shows retained personal dungeon defeats, not complete lifetime totals, clears, or lockouts. Classic Zul’Gurub boss tips are reviewed references, not live mechanics qualification.
- **Ask about saved Workshop materials offline.** Supported questions can be answered without a model or provider; the offline exchange is excluded from later provider history and memory reuse.
- **Platform and sharing limits.** macOS reports saved-only operation; native screen capture is not shipped or qualified. Quest-giver qualification is local groundwork only: no new sharing transport, consent defaults or server deployment. Live WoW, native Mac, and an installed Windows update/rollback are not certified by automated fixtures.

Back up your journal before switching versions; a compatible journal/checkpoint is not a promise that an older app preserves every field after a newer game import.
