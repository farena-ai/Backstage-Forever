# Backstage Forever 0.16.0 — your game's own maps, live

From Backstage Coding. Designed by Frank Arena.

**Real zone maps.** The World Map and the pop-out radar now draw each zone's actual map art, read from your own WoW Forever installation, with every explored-area detail filled in: roads, towns, rivers and landmarks. Your live arrow, quest markers, flight masters, trainers, vendors, herbs and ore sit on the real terrain. The art is read on your PC and cached per game build. Nothing is bundled with the app, uploaded or shared. If the game folder isn't connected, or a zone has no art, the map falls back to the parchment style.

**Live link on by default.** New installs and every character start with the live game link on, so you don't need `/bf live on`. The first time a character logs in, the addon says once in chat what the tiny top-left strip is and that `/bf live off` hides it. Turning it off, in Settings → Game connection or in game, is remembered.

**Clearer status.** When your position isn't live, the World Map says why: WoW is minimized, the window is covered, the link is off, or the game isn't running.

App, lockfile, addon TOC and capture metadata align at **0.16.0 preview**. **1.0 remains held for Frank's hands-on acceptance.**
