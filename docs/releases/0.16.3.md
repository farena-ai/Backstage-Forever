# Backstage Forever 0.16.3 — new characters explained

From Backstage Coding. Designed by Frank Arena.

**New characters.** WoW only saves addon data when you type `/reload` or log out, so the app can't see a character you just created until then. When you log in on a new character, the addon now says once in chat to type `/reload`. The World Map shows "WoW is on a new character · /reload once in game so the app can link it" instead of a vague "not live". If WoW is on a different saved character, the map tells you to switch characters.

**Consistent character match.** Live updates that arrive while the World Map is open now go through the same character check as everything else.

Builds on [0.16.2](0.16.2.md) (a live arrow you can see) and [0.16.0](0.16.0.md) (real zone maps from your own install).

App, lockfile, addon TOC and capture metadata align at **0.16.3 preview**. **1.0 remains held for Frank's hands-on acceptance.**
