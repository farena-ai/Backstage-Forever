# Backstage Forever 0.13.1 — Proactive Adventure preview

From Backstage Coding. Designed by Frank Arena.

The 0.13.0 candidate failed CI before publication; its tag and evidence are preserved. This 0.13.1 patch corrects the test fixtures and brings the same reviewed local improvements to the normal installed Windows update channel. **1.0 remains held for Frank's hands-on acceptance.** Earlier local review bundles and published releases remain unchanged.

## Delivery corrections

Recovery tests now match native Windows canonical paths under genuine 8.3 temporary roots and prove their crash/rollback injections actually run. The gathering retention test seeds validated history from a genuine collector result, then checks real overflow interactions instead of replaying 140 full gathers. Retention/export/deduplication assertions and the existing timeout remain intact. These are fixture corrections; product features, dependencies, reference data, formats and updater trust are unchanged.

## A useful next step

- **Proactive Compass:** one local recommendation and up to two alternatives for bags, observed quests, qualified learned recipes or profession training. Adventure, Quests and Professions change its priorities. Native guidance uses permitted current events; the desktop says **Last saved** and **No AI**. Unknown or partial supply cannot claim craft readiness, skill-ups or guaranteed output.
- **Quiet native controls:** Not now dismisses the current recommendation until relevant facts change. Quest details opens the existing focus/session controls. Hide, collapse, drag and manual supported waypoints remain available. The desktop and native goal preferences are independent.
- **One Professions workshop:** Adventure → Professions combines observed skills, learned recipes, carried materials and deliberate supply plans. Historical acquisition references remain visibly qualified; no bank/alt pooling, invented trainers, rank requirements or prices.
- **Map in both views:** open the game's map normally for BF Layers, historical material references and narrowly supported private finds. Adventure → Map shows last-saved coordinates, quests, historical standing points and your saved observations. It is a coordinate view, without terrain, automatic routes or active-resource claims.

## A clearer companion

The five main sections are Adventure, Quests, Companion, Characters and Plans. Settings holds Game connection, AI connection and Updates; Help → Field guide holds recovery, backups and support. Existing destinations and class/faction artwork remain. Conversations retain reviewed drafts, cancellation and context boundaries. Local sourced travel can offer conditional route cards and manual trip plans without a provider. Optional voice and saved memory remain deliberate, with per-question sharing choices.

Local diagnostics expose an allowlisted preview before copy/save. Bounded recovery checkpoints and damaged-journal recovery retain their disclosed privacy and deletion rules. No diagnostic upload, automatic AI question, paid fallback, new shared backend or new sharing consent is introduced. See [Privacy](https://github.com/farena-ai/Backstage-Forever/blob/v0.13.1/docs/PRIVACY.md) and [Support and recovery](https://github.com/farena-ai/Backstage-Forever/blob/v0.13.1/docs/SUPPORT-AND-RECOVERY.md).

## Reference limits remain visible

The acquisition subset contains seven selected relations and seventeen approximate historical player-standing points for build **1.60.1.70862**, from pinned November 9 observations. A **1.60.1.70888** character can browse those points only as older references. Native coverage is narrower than desktop seller browsing. Faction access, current availability, stock, skill/rank requirements and exact spawns remain unknown unless separately established. Private finds are past interactions, never active nodes or quantities collected. Supplementary quest notes and travel references retain separate provenance, licenses and coverage limits. No reference pack, game build, dependency, capture schema or protocol changes in this delivery step.

## Update when ready

Once this release is published, open **Updates → Check now** in installed 0.12.3, then choose when to install. Existing automatic download and install-on-exit preferences still apply; BF adds no forced restart. If needed, use the Windows setup executable from the [official 0.13.1 release](https://github.com/farena-ai/Backstage-Forever/releases/tag/v0.13.1). Source.zip is for developers.

Setup/repair verifies **twelve owned addon files**: TOC, Reference, Plan, Coach, Acquisition, Profession, Gathering, MapPlan, Map Lua, Map XML, capture and HUD. Unrelated files survive. Load updated files on the next game launch or a voluntary reload; file preparation alone does not prove live addon loading. The desktop receives changes when the game saves normally. Only characters visited with the addon enabled are known.

App-update authenticity uses the existing pinned Ed25519 manifest plus installer size/hash checks. Windows Authenticode publisher signing remains separate and pending. This release uses the existing public preview channel, without watcher jobs.

## What still needs hands-on acceptance

Automated source, Lua and synthetic GUI evidence does not certify the live client. Current-client Compass/Map rendering, zoom, gathering, interaction and performance; real provider entitlement/billing; microphone and playback quality; screen-reader behavior; clean-machine install/uninstall; and an actual installed self-upgrade remain separate checks. Public publication and authenticated downloaded assets are also verified separately from source preparation. **1.0 remains held until the owner reviews the real experience.**
