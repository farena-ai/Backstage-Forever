# Backstage Forever 1.0.1 — Found on a real Mac

From Backstage Coding. Designed by Frank Arena and Jason Babiuch. https://www.backstagecoding.com

We ran the 1.0 Mac app on a real Mac with WoW Forever installed. It found the game, installed the addon and drew the World Map from the Mac's own game files by itself. These are the things that weren't right yet.

**On a Mac you hear about new versions.** The app checks the same signed release feed as on Windows and says when a new version is out, in the side menu and in Settings → Updates, with a Download for Mac button. It never downloads or installs anything by itself: unzip the new version and drag it into Applications over the old one. Your journal stays.

**The Mac checklist finishes.** Now's "Get set up" list no longer waits for the live link, which isn't on Macs yet.

**Opening the Mac app the first time** on macOS 15 and later: System Settings → Privacy & Security → Open Anyway. README and Getting started explain it.

**The companion knows which side you mean.** "Where's the dwarf hunter trainer?" or "first aid in Stormwind" with no character shared now answers for the Alliance, measured from the place you name, and never sends a night elf to Mulgore. "The Undercity zeppelin to Orgrimmar" leaves from Tirisfal. "What drops linen cloth near Goldshire" lists nearby creatures, with their zone, first.

**Train where it makes sense.** With no class trainer in your zone, Now sends you to the capital next door (a Troll mage in Durotar goes to Orgrimmar, not across the sea to Tirisfal Glades).

**After updating:** Windows updates itself; on a Mac, download the new zip. Then type `/reload` in WoW once.
