# Backstage Forever 0.5.0

A character command center with automatic source-backed quest guidance and a final interface polish using the existing original class/faction artwork.

## Less setup, more useful guidance

Your local quest plan rebuilds from imported game snapshots without an AI connection. Choose a session length (15, 30 or 60 minutes) and focus (Balanced, Nearby or Turn-ins); preferences save per character. Session length limits the number of steps shown, rather than inventing completion-time estimates. Inspect why a step was suggested and which saved quest/objectives support it. Explain my plan prepares an AI question for you to review and send; no background inference runs.

This release covers observed quest-log guidance, not a complete quest database. It does not invent prerequisite chains, NPCs, rewards or missing destinations. Game-provided locations are references, not certified shortest travel routes. Stale/missing/manual profiles are identified explicitly. Desktop freshness remains the last saved snapshot, not a continuous live game feed.

## Character and preparation

Character-specific artwork, roster selection, compact connection/freshness status, XP and quest progress shape the command center. The repeated successful setup banner is removed. Private notes and goals remain local and survive imports.

Optional equipped-item and carried-bag-capacity observations use feature-detected public out-of-combat APIs. Missing/restricted APIs leave those details unknown without blocking identity capture. Preparation data is excluded from automatic provider context. Fixed friendly Compass capture messages replace silent indefinite waiting after a capture failure.

## Updating

Install the Windows setup executable normally. The companion prepares its updated addon automatically for an already connected game folder. If WoW is running, type `/reload` to load the updated addon; after it displays your character, use `/reload` again or log out to save the first updated capture to disk. The desktop imports it automatically. Do not expect clicking Refresh saved snapshot to flush game memory to disk.

Each additional toon must be played once with the addon enabled and exported. Optional Battle.net account roster linking remains research; 0.5 does not ask for account passwords or claim to import every unseen toon. See [Guidance](../GUIDANCE.md) and [Battle.net research](../BATTLE-NET-RESEARCH.md).

## Verification boundary

The release workflow runs unit, real Electron setup/UI/autosave/integration/command-center tests, builds the installer and checks packaged addon resources before publishing. Exact acceptance results are recorded in [Validation](../VALIDATION.md). Synthetic fixtures do not certify every Forever API, live provider entitlement or completion of a real installed self-upgrade.

Windows Authenticode publisher signing remains unavailable. App-update downloads have separate pinned Ed25519 signature and SHA256/size verification. No external release watcher jobs are created.
