# Backstage Forever 0.15.2 — live link on by default

From Backstage Coding. Designed by Frank Arena.

**Live link on by default.** New installs and every character now start with the live game link on, so the World Map arrow and the radar work without typing `/bf live on`. The first time a character logs in, the addon says once in chat what the tiny top-left strip is and that `/bf live off` hides it. If you turn it off, either in Settings → Game connection or in game, that choice is remembered.

**Clearer map status.** When your position isn't live, the World Map now says why: WoW is minimized, the window is covered, the link is off, or the game isn't running. A live arrow that has gone stale is cleared, and the "last saved" label sits on a readable plate.

Everything else from 0.15.1 is unchanged. App, lockfile, addon TOC and capture metadata align at **0.15.2 preview**. **1.0 remains held for Frank's hands-on acceptance.**
