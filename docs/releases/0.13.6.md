# Backstage Forever 0.13.6 — saved-character preview compatibility

From Backstage Coding. Designed by Frank Arena.

This preview candidate restores public previews of another saved character while preserving the selected character's conversation ownership. It carries forward local NPC guidance, honest current-location context and connection timing fixes. **1.0 remains held for Frank's hands-on acceptance.** Source preparation, Windows validation, publication and an authenticated public download are separate gates.

## Public previews keep their saved-character scope

The 0.13.5 candidate stopped before publication when Windows validation found that a read-only public preview of another stored character incorrectly required selecting that character first. Its tag, release notes and failed receipts remain preserved.

Version 0.13.6 restores that preview without changing character selection. Another character's preview shows its own approved saved facts. A current location typed for the selected character, or retained from its conversation, never transfers to the other character. Inspecting a preview does not change conversation, memory or provider state. Questions and memory actions still require the selected character; private notes, goals, account identifiers and credentials remain excluded from automatic context.

## Local NPC guidance and honest location context

Ask **Where is Cairne Bloodhoof?** or an exact **NPC #3057** in Companion. Supported NPC questions answer locally before any model, key or provider request. Compatible observed-build points take priority over a separate pinned historical reference covering 616 NPCs and 758 approximate interaction points from Forever build 1.60.1.70790. Each answer retains its build, per-NPC observation day, source and approximate/non-live limits. Unknown or unavailable evidence never becomes guessed coordinates.

Conflicting names across evidence tiers remain visible; an exact ID selects qualified evidence in tier order. Distinct NPC IDs sharing a name require clarification. Answers show at most three points and count additional observations; a point omitted from display is never treated as absent evidence.

A direct **I'm already in Org** report can supply a temporary planning city for the selected character's current conversation. The preview labels it user-reported and keeps the older saved location separate. Questions such as **I'm in Org?**, quoted AI prose, NPC city premises, saved memory and past/future/hypothetical statements cannot create a canonical report. Clear conversation retires both resolved and outstanding old previews; the next preview waits for the cleared conversation and matches the next send.

Reports expire with their retained turn, within six exchanges, and respect character/provider/source/sharing/memory/clear boundaries. They never update the saved journal or certify live game state. Sharing off omits automatic character context. All provider paths retain the same approved projection, including Claude's second context projection.

## Connection timing stays predictable

Connection checks and optional activation keep their current open or closed state during ordinary same-screen status updates. Focused disclosure summaries retain focus. Changing screen, character, setup session, folder or journal retires the old choice. Setup and Plans acceptance checks bind their evidence to the exact physical action and final guarded paint, preserving held-input and write-count checks.

App, lockfile, addon version and emitted capture metadata advance together to **0.13.6 preview**. Dependencies, game schemas/protocols, provider authentication, audio and update trust are unchanged. The existing quest reference remains separately pinned. Earlier release notes and tags remain unchanged.

## Update after publication

Once 0.13.6 is published, installed 0.12.3 or 0.13.4 can receive it through the existing authenticated preview channel. Open **Updates → Check now**, then choose when to install. Existing automatic-download and install-on-exit preferences apply; no intermediate installation or forced restart is needed. Use only the Windows setup executable from the [official release](https://github.com/farena-ai/Backstage-Forever/releases/tag/v0.13.6); source archives are for developers.

Setup continues to verify twelve owned addon files and preserve unrelated files. Signed-manifest, installer-size and hash checks remain mandatory. Windows publisher signing remains separate and pending. Local synthetic evidence does not certify live game behavior, real provider entitlement, audio quality, clean-machine installation or an installed self-upgrade. **1.0 stays held until Frank reviews the real experience.**
