# Backstage Forever 1.8.0 — Living Journal

- **Now and World Map:** a character-led dashboard puts the next action first, charts recorded progress, and keeps map controls and selections easy to reach.
- **Badge Case:** 54 character badges and seven account badges, searchable from Now and the character journal. Use `/bf badges pin` for supported in-game Compass goals.
- **Resumable goals:** pin a quest, profession checkpoint, or reputation target per character. Desktop pins do not sync back to WoW, and completion requires matching saved evidence.
- **Adventure Compass and Dungeon Atlas:** a dismissible current-map hand-in, clearer dungeon preparation, and a recap of confirmed saved encounters. The recap is not a record of clears or personal loot.

The Windows installer is timestamped and signed by Frank Arena through Azure Artifact Signing. Automated checks and isolated Windows packaging tests cover this build. Real WoW Forever validation is still in progress; report gameplay issues with the app/addon version and the steps to reproduce. Back up your journal before updating.
