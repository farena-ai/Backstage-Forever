# Backstage Forever 1.27.0 — Search everything

<!-- whats-new: stable -->

<!-- change: search-everything | new | desktop | none -->
- **Search everything.** Press Ctrl+K anywhere in the app and type: quests, NPCs, items, spells, talents, recipes, zones, dungeons, bosses, rare enemies, flight points, boats, commands and help pages. Pick a result and the app opens the right screen at the right thing. Each row says where the fact comes from: your game files, the bundled reference, or the community.

<!-- change: community-map-layers | new | desktop | none -->
- **Community map layers.** The World Map draws what players have shared as five layers: herbs, ore, chests, NPCs and vendors, each with how many players saw it and how old the data is. Zones with thin data show a short "help fill this zone" card.

<!-- change: wider-find | improved | addon | none -->
- **Wider `/bf find`.** It also finds quests players have met (pointing at the giver), dungeons and bosses, and the box on the in-game map lists up to eight results to click.

<!-- change: one-window-bags | new | addon | none -->
- **One-window bags.** `/bf bag` shows every bag in one window with search, categories, a glow on new items and marks for upgrades, wishes, quest items and junk. It is a finder: it never uses, moves or sells anything. Off until you turn it on.

<!-- change: chat-tools | new | addon | none -->
- **Chat tools.** `/bf chat` has four switches: timestamps, class-coloured names, copy and click links (web addresses and coordinates such as "45.2, 61.8"), and a careful filter for gold-seller lines that never touches friends, guild or whispers. All off until you turn them on.

<!-- change: settings-profiles | new | desktop,addon | none -->
- **Settings profiles.** `/bf profile` saves all your addon settings as one code you can keep, share or import, and the desktop can send a profile to another character. An import always keeps an undo.

<!-- change: zone-links-fix | fixed | desktop | none -->
- Zone tiles and links that pointed at a zone by its map number now open that zone.

<!-- change: unverified-in-game-127 | compatibility | desktop,addon | none -->
The bag window, chat tools, profiles and the new find panel have not been checked in the real game client yet. Search and map layers are new; if a result opens the wrong place, use Help → Report a problem.
