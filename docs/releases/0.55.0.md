# Backstage Forever 0.55.0 — Mac

From Backstage Coding. Designed by Frank Arena.

**Backstage Forever on a Mac.** This release adds a Mac app for Apple Silicon (M1 and later) and Intel Macs. Download `Backstage-Forever-0.55.0-macOS-arm64.zip` (Apple Silicon) or `-macOS-x64.zip` (Intel) from this release, unzip it and drag **Backstage Forever** into Applications.

**The first time you open it.** The Mac app isn't signed with an Apple developer certificate yet, so macOS stops it the first time. Open it once, then go to **System Settings → Privacy & Security**, scroll down and click **Open Anyway**. If macOS says the app "is damaged", open Terminal and run `xattr -cr "/Applications/Backstage Forever.app"`, then open it again.

**What works on a Mac.** It finds WoW Forever in Applications, installs and updates the addon, and reads your saves: Now, Adventure, the World Map, Quests, Characters, Ledger, Plans and the companion with your own AI provider all work, and everything in game works as on Windows.

**What doesn't (yet).** The live link (your position and progress while you play) is Windows-only, so the app catches up when the game saves, on logout or `/reload`. The built-in free AI, reading steps aloud, starting the game from the app and automatic updates are Windows-only too: on a Mac, download new versions from the releases page.

**Windows:** nothing changes for you in this release.
