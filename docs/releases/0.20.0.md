# Backstage Forever 0.20.0 — Alliance too, and every command explained

From Backstage Coding. Designed by Frank Arena.

**Alliance players get real advice.** The reference data now comes from the newest community snapshot, merged across four game builds. Elwynn Forest, Westfall, Redridge, Stormwind and Teldrassil now have quest givers, hand-ins and trainers on the map, on Now, and in the in-game BF Guide and `/bf next`. Horde zones grew a lot too. A few Alliance zones (Dun Morogh, Ironforge, Loch Modan, Wetlands, Duskwood) are still thin; they fill in as more players contribute.

**Smarter suggestions.** Now never sends a new character to another race's starting area.

**Every command, explained.** Help → Commands lists everything you can type in game, what it does in plain English, when to use it and an example you can copy. It also describes what you'll see in game and what each page of the app is for. It stays up to date: the build fails if a command is missing.

After updating, type `/reload` in game.

App, lockfile, addon TOC and capture metadata align at **0.20.0 preview**. **1.0 remains held for Frank's hands-on acceptance.**
