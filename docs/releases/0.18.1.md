# Backstage Forever 0.18.1 — hand-ins you can see in game

From Backstage Coding. Designed by Frank Arena.

**Hand-ins always show.** Finished quests now get a BF Guide pin. It uses where WoW itself marks the hand-in, then the community reference, then the quest giver, where quests are usually returned. `/bf next` points at the nearest hand-in first. The Now page uses the same fallback.

**On top, not underneath.** BF Guide pins draw above WoW's quest markers, so your class trainer and quest pickups aren't hidden.

**Tidier map panel.** The BF Layers panel now sits inside the map area, so reskinned map frames can't cover it.

**Clearer wording.** Now says "Next spells at level 8", so it can't be read as your level.

After updating, type `/reload` in game.

App, lockfile, addon TOC and capture metadata align at **0.18.1 preview**. **1.0 remains held for Frank's hands-on acceptance.**
