# Backstage Forever 0.16.2 — a live arrow you can see

From Backstage Coding. Designed by Frank Arena.

**Easier to spot.** On the real zone maps added in 0.16, the old gold arrow blended into the gold terrain. Your live position is now a bright blue arrow on a dark disc, turning red in combat, with a blue trail behind you. The radar uses the same marker.

**Stricter character match.** A live position is used only once the app has read that character from the addon's saved data, so another character's position can never appear on yours.

This builds on [0.16.1](0.16.1.md), which fixed live positions being ignored, and [0.16.0](0.16.0.md), which added real zone maps from your own install.

App, lockfile, addon TOC and capture metadata align at **0.16.2 preview**. **1.0 remains held for Frank's hands-on acceptance.**
