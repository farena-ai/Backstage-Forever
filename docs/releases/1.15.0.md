# Backstage Forever 1.15.0 — Guild Run Pack

<!-- whats-new: stable -->

<!-- change: guild-run-pack | new | desktop | none -->
- **Plan a guild run in Plans → Party → Guild Run Pack.** Preview an event with its organizer time zone, meeting point, roles and preparation checklist. Save it locally, then export a JSON pack or plain-text copy to share yourself. Recipients can review a pack before saving it, apply later revisions or cancellations, and keep their own preparation checks private. There is no account, RSVP collection, automatic delivery or sync.
