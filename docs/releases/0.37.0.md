# Backstage Forever 0.37.0 — painted zone banners

From Backstage Coding. Designed by Frank Arena.

**Entering a new zone is an event now.** The see-through black box with the zone name is gone. In its place is a solid painted banner at the same size, with its own original painting for every zone and capital: Durotar's red canyons, Elwynn's meadows, the Tanaris dunes, Winterspring's snow, the six capitals and Moonglade, Alliance and Horde alike. The zone name sits on top in gold, with the zone's level range and how many quests are there for your level on a ribbon underneath.

- 46 paintings, all original art made for Backstage Forever. Any other map (a dungeon, say) gets a default landscape.
- The same painting now heads that zone's card on the app's Now page, in the "Where to level" list and on the Adventure page, so the game and the app match.
- As before, it waits while you're in combat, skips the first zone after you log in, writes one line in chat, and `/bf toasts off` turns it off.

The addon is larger this time (about 18 MB of paintings), so the update takes a little longer to install.

**After updating:** type `/reload` in WoW once.
