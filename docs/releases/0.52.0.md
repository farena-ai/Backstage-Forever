# Backstage Forever 0.52.0 — accessibility

From Backstage Coding. Designed by Frank Arena.

**For screen readers.** Every page and window was checked: every button and field has a name, every picture a description, and every window says what it is. Mini Now's step and the ask panel's answers are read out when they change.

**For the keyboard.** The focus ring always shows where you are, on every page. The World Map moves with the arrow keys: + and - zoom, 0 shows the whole zone. Every pin can also be reached through the search and the lists beside the map.

**For colourblind players.** Item cards now write the quality out ("Uncommon · One-Hand Sword") instead of relying on the name's colour. Map pins already use a different painted icon for each kind.

**Easier to read.** Small labels on the newer pages and the in-game step scroll are darker, so they meet the usual contrast standard (WCAG AA).

**Less motion, high contrast.** If Windows is set to show less animation, the app's drifting banners and effects stop. Windows high-contrast themes keep buttons, cards and progress bars outlined.
