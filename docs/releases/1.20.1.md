# Backstage Forever 1.20.1 — Real icons for hotfix loot

<!-- whats-new: stable -->

<!-- change: hotfix-item-details | fixed | desktop | atlas -->
- Dungeon loot the game delivers as a hotfix now shows its real icon, quality colour, slot, stats and damage, and gets an "Upgrade for you" verdict like any other item. 1.20.0 could show only its name and a painted pouch. On a current install this fills in several thousand items across Dungeons & raids, item hover cards, gear comparison and the Ledger.

<!-- change: hotfix-cache-source | compatibility | desktop | none -->
The details come from the hotfix cache the game keeps in its own folder (`Cache/ADB`). Backstage Forever only reads that file, on your computer; it is never changed, uploaded or bundled. A cache written by another game build is ignored, and a row that does not fit the expected layout is skipped, so the item keeps what your game files say. When the game receives new item hotfixes, the app reads items again the next time it needs them. If the game has not written a cache yet (a fresh install that has never logged in), these items still show name-only as before.
