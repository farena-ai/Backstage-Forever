# Backstage Forever 0.30.1 — no more "blocked action" notice

From Backstage Coding. Designed by Frank Arena.

**Fixed:** WoW could show "Backstage Forever has been blocked from an action only available to the Blizzard UI". The journal (added in 0.28) hid its quiet `/played` chat line by swapping out one of WoW's own chat functions, which the game treats as tampering with its interface. It now simply mutes the chat windows for that one answer and leaves Blizzard's code untouched. A new test checks that no addon file ever replaces a Blizzard function.

**After updating:** type `/reload` in WoW once. If WoW asks you to disable the addon, choose Ignore; the fix is in this version.
