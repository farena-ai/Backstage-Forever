# Backstage Forever 0.7.0 — Living Companion

Useful quest guidance inside WoW, easier companion preparation and more reliable saved-character switching. The native local planner works without an AI account or the desktop app running.

**[Download the Windows installer](https://github.com/farena-ai/Backstage-Forever/releases/download/v0.7.0/Backstage-Forever-0.7.0-Windows-x64-Setup.exe)** · [Living Companion guide](https://github.com/farena-ai/Backstage-Forever/blob/v0.7.0/docs/LIVING-COMPANION.md)

## Play with the Compass

Adventure Compass now builds a compact next-step plan from current public quest observations outside combat. Quest progress, ready turn-ins, XP/levels and supported location events update it without routine reloads. Focus and session controls remember your character's choices. Session size is not a guaranteed completion-time estimate.

Current game titles, objectives and markers take priority. Compatible bundled references can add approximate locations with clear source/relationship labels. A mentioned NPC never becomes an invented finisher, and missing facts stay unknown. The explicit waypoint button identifies its step and source, rechecks the live quest/build guards and places a supported marker or prints coordinates. All movement and game actions remain yours.

The Compass still uses native WoW textures, dragging, close/collapse and per-character positioning. It hides during combat and resumes outside combat. Use **/bf show**, **/bf hide** or **/bf status**. Source and quest-phase labels have reserved space beside the waypoint action, so a long title cannot hide the qualifier.

## Start my adventure

One primary action discovers and prepares a single validated Forever installation. Several installations produce a choice; no discovery result offers a folder button. Once files are prepared, you can enter BF or play without waiting for an initial desktop capture or connecting AI.

Local running-game awareness helps explain the next step. Open Forever uses only the configured validated executable on your explicit click; ordinary launcher/login use remains available. Unknown runtime status does not block setup. BF does not read game memory, automate authentication, install an OS service or force a reload.

Five managed addon resources are staged and verified, with the loader committed last and bounded application rollback on failure. Unrelated addon files remain untouched. This is not a guarantee of filesystem crash/power-loss atomicity.

## Your saved characters

BF combines valid primary saved exports from account folders in the connected installation. Per-character timestamps prevent one character's later overall save from suppressing a legitimate update for another. Invalid/transient files preserve good profiles; capacity/omitted coverage is reported. Notes, goals and intentional manual selection stay intact.

Following still applies to saved game data. Re-enabling it can immediately select the current connection's already-known saved active character when freshness guards permit. Characters never visited with the addon enabled cannot be discovered by this system.

## Activate this update

Install/restart BF normally and let it prepare the companion. Prepare before launching WoW when possible. If WoW is already running with the addon installed, a voluntary **/reload** can load the update; otherwise load it on the next game launch. A newly added addon that is not listed may require a game restart.

Once loaded, native guidance updates while you play without routine reloads. Let logout/game exit save naturally for the desktop. If you specifically want fresh desktop or AI context immediately, voluntarily reload to save it. The desktop remains last-saved; it does not have a continuous character feed. Another save after loading an updated addon may be needed to deliver its first new capture, but is not required to use its native guidance.
