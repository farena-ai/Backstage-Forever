# Backstage Forever 0.13.7 — packaged validation cleanup

From Backstage Coding. Designed by Frank Arena.

This preview candidate corrects how the packaged Windows acceptance check shuts down and removes its disposable test copy. It carries forward the reviewed NPC guidance, honest current-location context, saved-character previews and connection timing work. **1.0 remains held for Frank's hands-on acceptance.** Source preparation, Windows validation, publication and authenticated delivery remain separate gates.

## Finish the test before reporting success

The 0.13.6 candidate passed packaged startup/restart, 133 reviewed source/data/key byte matches, SDK loading and twelve-file addon install/readback/repair. Windows then reported the disposable executable as busy during cleanup, so the release stopped before publication. Its tag, notes and failed receipt remain preserved, alongside the unpublished 0.13.5 candidate.

The acceptance check now waits for application shutdown and the exact launched child process to close before restarting or deleting the test copy. It verifies the resolved temporary folder and its owned name before recursive work. Short Windows sharing locks receive a bounded retry budget; stubborn locks and shutdown errors remain failures. The final PASS message appears only after cleanup finishes.

These changes target the disposable test copy. They do not change the installed app's shutdown behavior, updater, journal handling or provider connections. All packaged functional assertions remain intact. Actual acceptance of a freshly built 0.13.7 package remains required; an older local build is not proof for this candidate.

## The reviewed preview features remain

Supported NPC names and exact IDs receive local sourced location answers before model/key/provider access. Compatible observed-build points take priority over a separately qualified historical reference of 616 NPCs and 758 approximate points. Unknown or unavailable evidence stays unknown. Names, coordinates, build, per-NPC observation day and non-live qualifications remain visible.

Direct current player reports stay distinct from saved snapshots and remain bounded to the current character/conversation. Other-character public previews contain only that character's approved saved facts. Sharing opt-out, strict question/memory ownership, held-clear preview/send parity and conservative treatment of questions or quoted prose remain. Connection disclosures retain their same-screen open/closed choice and focused summary through ordinary status paints.

App, lockfile, addon TOC and emitted capture metadata advance together to **0.13.7 preview**. Dependencies, datasets, game schemas/protocols, provider authentication, audio and update trust are unchanged. Earlier release notes and tags remain unchanged.

## Update after publication

Once 0.13.7 is published, installed 0.12.3 or 0.13.4 can receive it through the existing authenticated preview channel. Open **Updates → Check now**, then choose when to install. Existing automatic-download and install-on-exit preferences apply; no intermediate installation or forced restart is needed. Use only the Windows setup executable from the [official release](https://github.com/farena-ai/Backstage-Forever/releases/tag/v0.13.7); source archives are for developers.

Signed-manifest, installer-size and hash checks remain mandatory. Windows publisher signing remains separate and pending. Synthetic acceptance does not certify live game behavior, real provider entitlement, audio quality, clean-machine installation or an installed self-upgrade. **1.0 stays held until Frank reviews the real experience.**
