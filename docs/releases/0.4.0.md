# Backstage Forever 0.4.0

Set up the companion from first launch or after upgrading. The guided flow discovers the Forever client or offers a folder picker, prepares and verifies its three addon files, repairs missing/outdated owned files, and explains the next action. Enable/load the addon in-game, then voluntarily `/reload` or log out to save a desktop snapshot.

## Adventure at a glance

The local dashboard shows observed quests/objectives, ready turn-ins, available XP, actual game-provided waypoints and up to 25 recent turn-ins observed while tracking. An optional public completed-count is separate from recent history. The draggable/collapsible in-game Adventure Compass updates out of combat and hides during combat. Use `/bf show`, `/bf hide` or `/bf status`.

Desktop imports still check saved files every five seconds and require the game's reload/logout write. This is not a complete historical quest database or optimal route planner. Missing/restricted APIs stay unknown. Race/faction use separate public game readings without a fixed race whitelist.

## Less clicking, clearer context

Provider/model choices save immediately; text settings, notes and encrypted API keys save when you leave the field. Visible save status supports retry, and a secondary Save remains available. Enter submits an explicit AI question; Shift+Enter inserts a line and input-method composition is respected. No AI question runs in the background.

The default-on active-character context has a persistent opt-out and exact preview. It includes bounded public identity, race/faction, quests/objectives, XP, actual destinations and recent observed history. Private journal content, goals, paths, raw GUIDs and account identifiers remain excluded. API billing and subscription access remain separate; Grok subscription is unavailable and xAI API remains available.

Original painted artwork is joined by sculpted controls, gems/runes and ambient motion with reduced-motion and hidden-window handling. Optional schema fields preserve version-1 backups. Stable character form targets and journal merging protect edits during newer imports.

## Verification and limits

See [Validation](../VALIDATION.md) for measured results. Packaged addon preparation is a release gate because the previous source-only tests missed a shipped-bundle file-access regression. Actual client loading/HUD acceptance, live subscription consent/paid inference, clean-machine install/self-upgrade and Windows Authenticode remain separate gates. Ed25519 update integrity does not sign the Windows publisher identity.

136 automated checks passed, plus real Electron setup/autosave/UI/integration tests. Slow catalog discovery cannot block navigation after a successful save. Independent review verified the export-size and current-folder readiness fixes.

Download availability and final artifacts are established by the public [Releases page](https://github.com/farena-ai/Backstage-Forever/releases), not by this feature list. No external release watcher job is created.
