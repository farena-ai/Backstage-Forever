## Your adventure, explained

- **Adventure Director:** one explained next quest action, up to two alternatives and one-click tracked Company sessions. Session length limits plan size; it is not a promised completion time.
- **Preparation:** observed professions, learned recipes, dated carried materials and deliberate manual shopping checklists. Complete and partial observations remain distinct; other characters are kept separate.
- **Optional local voice:** hold to create an editable draft, release and review before Send. Explicit local answer/plan reading and Stop are separate. Typed input remains available when engines or permissions are unavailable.
- **Private character memory:** review and save an exchange deliberately. Select specific saved exchanges separately for each future question and inspect the preview. Backups exclude memory; replacement import/reset clears it.
- **Party:** choose your role and create a manual dungeon checklist. Preview/edit every portable line before export or explicit import. Imported plans receive new local IDs and unchecked, unassigned manual steps without completion proof. Sharing stays under your control.

## Update and begin

Use **Updates** to check the official Windows preview, then restart when ready. If an older installation cannot download it, close BF and get the Windows setup executable from the [official release](https://github.com/farena-ai/Backstage-Forever/releases/tag/v0.12.1). The Source ZIP is for developers; normal installation does not need Node.js.

Let BF prepare/verify its five companion files. Load the updated addon on the next game launch, or use one voluntary `/reload` if WoW is already running. Native guidance updates outside combat without routine reloads. The desktop receives changes when WoW saves on logout/game exit or optional UI reload. Only characters visited with the addon enabled can be known.

App-update downloads use the existing pinned Ed25519 manifest and installer size/hash checks. Windows publisher signing is separate and remains pending. Gameplay inputs, movement, purchases, crafting and sharing remain deliberate player actions. No always-on recording, automatic AI question or new party service is introduced.
