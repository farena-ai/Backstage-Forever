# Backstage Forever 0.43.0 — all characters at a glance

From Backstage Coding. Designed by Frank Arena.

**Characters → All characters.** Every character on one page: class portrait, level, how far through the level, rested XP, gold, free bag slots, professions, where they are and when you last played them. Click **Switch to** on a card to make that character the active one.

**Rested XP keeps counting.** The page works out how much rested XP each character has built up since you logged out: about 5% of a level every 8 hours in an inn or a city, a quarter of that elsewhere, up to 150%. From this version the addon remembers whether you logged out in a rested spot. Until each character has been saved once with 0.43, the page shows a range.

**Who to play tonight.** At the top, the page suggests a character and says why: "rested XP is full, so every hour away is wasted", "one level from 40 and riding", "not played for 20 days". It also warns when a character's bags are nearly full.

**After updating:** type `/reload` in WoW once on each character, so the addon saves the new rested flag.
