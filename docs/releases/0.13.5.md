# Backstage Forever 0.13.5 — connection timing preview

From Backstage Coding. Designed by Frank Arena.

This preview candidate keeps connection details where you left them while status checks finish. **1.0 remains held for Frank's hands-on acceptance.** Source metadata, Windows validation, publication and an authenticated public download are separate gates.

## Connection checks stay put

Opening **Connection checks and tools**, **Optional activation during this session**, or setup **Connection checks** is no longer undone by an ordinary status paint on the same screen. Closing a panel keeps it closed. A focused disclosure summary retains keyboard focus after that paint.

The choice belongs to the current screen, character and setup session. Navigation, character changes, an explicit folder choice, disconnection and journal replacement retire the old choice. It is temporary display state, with no new stored preference or consent. Existing artwork, five-section navigation and recovery controls remain.

## More reliable setup and Plans checks

The actual Windows acceptance checks now distinguish a physical click from its completed renderer action and final paint. Setup navigation and Refresh acknowledge the exact intended action. A renamed plan must own its current card, exact updated Delete label and natural keyboard focus before the next gesture begins. Privacy, cancellation, original-node held-input checks, independent write counts and deadlines remain intact.

Dependencies, reference facts, game schemas/protocols, provider behavior, audio and update trust are unchanged. App, addon version and emitted capture metadata advance together to 0.13.5 preview. Earlier release notes, tags and failed receipts are preserved.

## Update after publication

Once 0.13.5 is published, installed 0.12.3 or 0.13.4 can receive it through the existing authenticated preview channel. Open **Updates → Check now**, then choose when to install. Existing automatic-download and install-on-exit preferences apply. No intermediate installation or forced restart is needed. Use only the Windows setup executable from the [official release](https://github.com/farena-ai/Backstage-Forever/releases/tag/v0.13.5); source archives are for developers.

Setup still verifies twelve owned addon files and preserves unrelated files. Prepared files and a saved capture do not prove live client acceptance. Existing signed-manifest, installer size and hash checks remain mandatory; Windows publisher signing remains separate and pending.

## Acceptance still held

Synthetic setup and Plans evidence does not certify real provider entitlement, microphone/playback quality, live game behavior, full accessibility, a clean-machine installation or an installed self-upgrade. Independent review and release validation precede publication. **1.0 stays held until Frank reviews the real experience.**
