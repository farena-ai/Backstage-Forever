# Backstage Forever 0.13.5 — local NPC guidance and connection timing preview

From Backstage Coding. Designed by Frank Arena.

This preview candidate answers supported NPC-location questions locally, distinguishes current player reports from saved locations, and keeps connection details where you left them while status checks finish. **1.0 remains held for Frank's hands-on acceptance.** Source metadata, Windows validation, publication and an authenticated public download are separate gates.

## Sourced NPC locations, without an AI connection

Ask **Where is Cairne Bloodhoof?** or an exact **NPC #3057** in Companion. Recognized NPC questions are answered locally before any model, key or provider request. Full and unique short names are supported; ambiguous names ask for an exact ID. Unknown or unavailable NPC evidence stays unknown. Item, material, bank and geography questions retain their ordinary planning path.

Compatible observed-build NPC points take priority. A separate pinned historical Forever reference covers 616 NPC identities and 758 approximate interaction points from build 1.60.1.70790. It can place Cairne's historical observation in Thunder Bluff around 59.9, 51.7, last seen November 5, 2026; it cannot verify his live presence or absence in Orgrimmar. Each answer names its build, NPC observation day, source and approximate/non-live limits. These are public player observations from Efficient Games under CC BY 4.0; NPC file collection November 9–11 is distinct from each NPC's last observation.

## Current reports and saved snapshots stay distinct

A direct **I'm already in Org** report can supply the current planning city in the current conversation. It is labelled user-reported, and the older saved location remains separately labelled in the public context preview. Asking **where in Org is Cairne** does not itself report the player's location or prove Cairne is there. Quoted AI text, saved exchanges, past/future and hypothetical statements do not create a current location report.

Reports are temporary, bounded by the retained six exchanges and existing character/provider/source/sharing/memory/clear boundaries. They never update a character's saved journal or become live game telemetry. Sharing off continues to omit the automatic character payload. All provider paths, including Claude's second context projection, share these rules. Desktop location is always last saved even when its timestamp is today; native Compass receives supported current events inside WoW.

## Connection checks stay put

Opening **Connection checks and tools**, **Optional activation during this session**, or setup **Connection checks** is no longer undone by an ordinary status paint on the same screen. Closing a panel keeps it closed. A focused disclosure summary retains keyboard focus after that paint.

The choice belongs to the current screen, character and setup session. Navigation, character changes, an explicit folder choice, disconnection and journal replacement retire the old choice. It is temporary display state, with no new stored preference or consent. Existing artwork, five-section navigation and recovery controls remain.

## More reliable setup and Plans checks

The actual Windows acceptance checks now distinguish a physical click from its completed renderer action and final paint. Setup navigation and Refresh acknowledge the exact intended action. A renamed plan must own its current card, exact updated Delete label and natural keyboard focus before the next gesture begins. Privacy, cancellation, original-node held-input checks, independent write counts and deadlines remain intact.

Dependencies, game schemas/protocols, provider authentication, audio and update trust are unchanged. The existing quest reference remains separately pinned; this release adds the distinct historical NPC reference and shared location-context rules. App, addon version and emitted capture metadata advance together to 0.13.5 preview. Earlier release notes, tags and failed receipts are preserved.

## Update after publication

Once 0.13.5 is published, installed 0.12.3 or 0.13.4 can receive it through the existing authenticated preview channel. Open **Updates → Check now**, then choose when to install. Existing automatic-download and install-on-exit preferences apply. No intermediate installation or forced restart is needed. Use only the Windows setup executable from the [official release](https://github.com/farena-ai/Backstage-Forever/releases/tag/v0.13.5); source archives are for developers.

Setup still verifies twelve owned addon files and preserves unrelated files. Prepared files and a saved capture do not prove live client acceptance. Existing signed-manifest, installer size and hash checks remain mandatory; Windows publisher signing remains separate and pending.

## Acceptance still held

Synthetic setup and Plans evidence does not certify real provider entitlement, microphone/playback quality, live game behavior, full accessibility, a clean-machine installation or an installed self-upgrade. Independent review and release validation precede publication. **1.0 stays held until Frank reviews the real experience.**
