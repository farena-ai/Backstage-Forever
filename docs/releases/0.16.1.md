# Backstage Forever 0.16.1 — live position shows in the app

From Backstage Coding. Designed by Frank Arena.

**Live arrow fixed.** In 0.16.0 the game sent its live position correctly, but the app rejected it, so the World Map kept showing "Last saved position" and the companion didn't get live context. The app keeps only a private digest of each character's game id, and it was comparing that digest with the addon's live key instead of the key itself. The app now learns each character's live key while reading the addon's saved data, so your own frames are accepted and frames from another character are still ignored.

Everything else from [0.16.0](0.16.0.md) is unchanged: real zone maps from your own install, and the live link on by default.

App, lockfile, addon TOC and capture metadata align at **0.16.1 preview**. **1.0 remains held for Frank's hands-on acceptance.**
