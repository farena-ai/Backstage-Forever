# Backstage Forever 0.57.0 — Getting ready for 1.0

From Backstage Coding. Designed by Frank Arena.

**More German.** Sentences with numbers and names in them are now German too: "Gib 3 fertige Quests ab", "Stufe 21: komm um Stufe 29 wieder", your character line, dungeon levels, the guided route steps and the gear slots. What stays English are the names of quests, items and places, as in the game data. The German is still marked as machine-translated.

**Updates after 1.0.** Once you're on 1.0, the app only updates to full releases, never to a test version.

**The road to 1.0.** The [roadmap](../ROADMAP.md) now says for every feature whether it's done, partly done or planned for after 1.0. The [1.0 checklist](../ACCEPTANCE-1.0.md) lists what gets checked by hand in the real game before 1.0.

**Mac:** the Mac downloads are on this release, as in 0.55.1.
