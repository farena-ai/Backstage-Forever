# Backstage Forever 1.11.0 — Dungeon preparation, savings goals, and quest-chain progress

**Local candidate; not published.** Changes since v1.10.0:

- **Prepare for a dungeon offline.** Ask Companion `Dungeon prep for The Deadmines?` using a supported Atlas name or exact `#ID`. No model or account is needed. With active-character context enabled, the answer can show possible matches in the saved quest log and starred loot references compatible with the saved build. This is not proof of quest eligibility, personal drops, clears, lockouts, or live mechanics. The exchange is excluded from provider history and cannot be saved to Companion Memory.
- **Turn a Workshop estimate into a savings goal.** Review a priced estimate before setting or replacing the Ledger goal. An unpriced batch cannot set a goal. Switching characters or changing the goal while a review is open makes the old confirmation ineligible. The estimate is not a current market price or a purchase instruction.
- **See progress on reviewed quest chains.** Unfinished quest-chain badges show completed steps from the saved character and the remaining reviewed steps when evidence is available. Progress does not award the badge early or establish quest eligibility.

The Tauren evidence review did not change shipped route coverage. Automated local qualification does not certify an installed Windows upgrade or rollback, a published update feed, live WoW behavior, or native macOS behavior. Back up your journal before switching versions.
