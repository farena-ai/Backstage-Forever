# Backstage Forever 0.42.0 — party sync

From Backstage Coding. Designed by Frank Arena.

**Quest together.** When you're in a party with players who also run Backstage Forever, the addons quietly swap quest progress. Type `/bf party` to see each member's quests next to yours: "Raptor Thieves: them 5/8, you 2/8", plus the quests only they have, so you can ask them to share.

**Shared waypoints.** `/bf party way` sends your waypoint to the party (or where you're standing, if you haven't set one). The others see "Ann shares a waypoint: Kolkar camp at 40.0, 60.5" and can type `/bf party go` to put the arrow on it.

Only quest numbers and objective counts are sent, only to your party, and never in raids. `/bf party off` stops sending and listening.

**After updating:** quit WoW and start it again once, because this version adds a new addon file.
