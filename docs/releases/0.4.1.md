# Backstage Forever 0.4.1

Fixes the in-game Adventure Compass remaining at “Waiting for a public character snapshot” despite loading successfully. Lua forwarded multiple class/race/faction API results into a string validator, causing capture to abort. The addon now explicitly uses the first result.

The Compass now uses WoW dialog textures and native close controls, a draggable title, a separate collapse button, content-sized height, and permanent hide/show instructions. Closing prints `/bf show` in game chat. Position, visibility and collapse preference are saved per character, separately from the desktop snapshot export; fully restart WoW once after this upgrade to ensure the new saved-variable declaration is registered.

After updating the desktop, let it prepare its addon files. In WoW, use `/reload` to load the corrected script. Once the panel displays your character, use `/reload` again or log out to flush that first successful snapshot to disk. Subsequent reloads/logout save the current captured state normally. This does not enable continuous disk streaming or gameplay automation.

Regression coverage executes realistic multi-return player APIs in the Lua VM and rejects interpreter errors independently of exit status. All 136 automated tests passed locally. Live verification in Forever confirmed the repaired HUD shows level, class, location, XP and nine observed quests after a player-triggered reload. A subsequent live reload produced a desktop snapshot import, and the updated native-style panel rendered with close/collapse controls, instructions and a moved position; no claim of complete quest API compatibility is made. Windows Authenticode signing remains unavailable; the app-update manifest is separately signed with Ed25519.
