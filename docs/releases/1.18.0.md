# Backstage Forever 1.18.0 — A front door in game

<!-- whats-new: stable -->

<!-- change: ingame-settings-window | new | addon | none -->
- One painted settings window for every in-game helper. Type `/bf options`, or right-click the owl on the minimap. Three pages (Quests, Alerts, Comfort) hold 29 switches; point at one to read what it does. Quiet, Leveling and Veteran set a group of switches at once and say how many changed. The window also shows which game build you are on and which build the quest data was checked on. It is listed in the game's own options too.

<!-- change: ingame-welcome-card | new | addon | none -->
- A painted welcome card on your first login: what the Compass does, what the owl does, and where to get the free desktop app. `/bf welcome` shows it again.

<!-- change: ingame-key-bindings | new | addon | none -->
- Four keys in the game's Key Bindings list under Backstage Forever: show or hide the Compass, point to your next quest stop, ask the companion, and open settings.

<!-- change: way-command | new | addon | none -->
- `/way X Y [name]`, the waypoint line players paste from guides and chat, now places an arrow on the map you are on. If another waypoint addon already answers `/way`, Backstage Forever leaves it alone.

<!-- change: perf-command | new | addon | none -->
- `/bf perf` says how much memory the addon is using and how that changed since you last asked.

<!-- change: companion-same-patch-data | fixed | desktop | none -->
- The Companion, the Now page and the adventure coach now get quest data for a character on another build of the same patch. 1.17.1 fixed this for quest lookups; these three still came up empty until that build had been downloaded.

<!-- change: boss-tips-installed | fixed | desktop,addon | none -->
- The desktop app now installs the boss tips file with the rest of the addon. Before, players who installed through the app were missing in-game boss tips.

<!-- change: ingame-settings-scope | compatibility | addon | none -->
Each switch runs the same `/bf` command you could type, and every setting still belongs to the character you are playing. Not yet checked in the real game: the entry in the game's own options list and the key bindings.
