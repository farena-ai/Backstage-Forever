# Backstage Forever 0.11.0 — Voice and private memory

Local development milestone; delivered publicly with the combined 0.12 release. This is a preview checkpoint before Frank Arena's hands-on 1.0 review.

## Speak deliberately, send deliberately

Optional Windows dictation turns a held control into an editable question draft. Releasing it, losing focus or changing context stops input; dictation never sends a question. Existing text remains protected, and conflicting edits leave a separate draft for explicit insertion. Typed questions remain available when compatible local speech is unavailable.

Read an answer or public plan explicitly with an installed compatible local voice. Stop interrupts reading; beginning dictation stops BF's own reading first. Capability discovery does not prove microphone permission or audible playback. If a helper's termination cannot be confirmed, BF blocks replacement audio instead of starting overlapping workers. No audio files or cloud transcription are introduced.

## Remember only what you choose

Review and save an eligible exchange for the current character. Delete individual exchanges or clear that character's memory. Saving locally does not select it for a future AI question: choose specific exchanges separately and inspect the per-question preview before Send. Earlier conversation is unverified text, not game evidence.

Saved memory is readable local app data, excluded from profile exports, cleared on replacement import/reset and pruned with deleted characters. Provider credentials remain in their existing protected stores. Notes, goals and Company journeys are excluded from automatic AI context. Deleting local memory does not delete a provider's records.

See [voice and memory help](../VOICE-AND-MEMORY.md), [privacy](../PRIVACY.md) and [the owner check before 1.0](../OWNER-CHECK-012.md). Real microphone, recognition quality and playback acceptance remain player-led checks.
