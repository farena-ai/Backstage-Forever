# Backstage Forever 1.0.2 — Checksums that check on a Mac

From Backstage Coding. Designed by Frank Arena and Jason Babiuch. https://www.backstagecoding.com

**Checking your download works on a Mac.** The checksum list that comes with every release (`SHA256SUMS.txt`) was written with Windows line endings, so on a Mac `shasum -a 256 -c SHA256SUMS.txt` said most lines failed, even though the files were fine. It now uses plain line endings and checks cleanly on Mac, Linux and Windows.

Nothing else changes: same app and same addon as 1.0.1. Windows installs update by themselves; on a Mac, download the new zip and replace the app in Applications. Your journal stays.
