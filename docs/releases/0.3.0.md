# Backstage Forever 0.3.0 preview — your game-aware companion

From Backstage Coding. Designed by Frank Arena.

Use the Windows x64 setup executable from this repository's Releases page. Existing authenticated updates remain supported; 0.1.0 needs one manual installer upgrade.

## Connect your game

Open Game Connection, choose the Forever client folder and install/update the guarded addon with one click. Enable it in the game. Only characters you visit with the addon enabled can become known; there is no account-wide discovery API.

**Levelled up or changed areas? Type `/reload` in WoW to refresh your companion.** Logout also saves. The app checks for saved exports every five seconds while open, but WoW writes them only on reload/logout. Visible timestamps describe saved snapshots, not a continuous live feed. The newest account snapshot supplies the last played character. Following starts enabled; deliberately selecting another profile pauses it until you restore its checkbox. Imports preserve notes, goals and unrelated manual profiles.

## Choose your AI

Model catalogs refresh on startup, connection opening, successful authentication, save and manual refresh. Failed refreshes keep your selection. No paid inference entitlement probes or silent model/provider/billing fallback occur. ChatGPT's account catalog determines visible subscription models; API catalogs and Claude CLI initialization do not guarantee plan entitlement.

Local Ollama remains an offline option with local models. Separate Ollama Cloud uses its own Bearer key and fixed `https://ollama.com` native chat. ChatGPT subscription access and API billing are separate. Claude subscription uses the official CLI with a private app profile and no API fallback. Grok subscription is still unavailable pending tools/hooks isolation; xAI API mode is available.

## A Forever specialist

The companion permanently assumes World of Warcraft: Forever. A local heuristic handles obvious unrelated questions before provider inference; shared policy guides permitted game questions. This is not a perfect semantic classifier. The app cannot execute code, automate play or provide live combat decisions.

Use my active character now defaults on with a persistent opt-out and preview. Submitted questions may include public name, realm, class, level, race, faction, location and snapshot timestamp. Raw GUIDs, account identifiers, paths, private notes and goals stay out of automatic context. There is no autonomous paid background inference.

Nine original class portraits and Alliance/Horde environments shape the dashboard, roster and journal, with neutral fallback. They are illustrations, not captured player portraits.

## Evidence and remaining checks

Local validation: 120 tests passed, plus real Electron UI, encrypted-storage/game-sync integration, Windows packaging and isolated packaged startup with SDK loading. See [Validation](../VALIDATION.md) and the release workflow for evidence. Real-game acceptance, live OAuth/account entitlement, paid inference and clean-machine/self-upgrade acceptance remain unverified. Ed25519-signed update manifests authenticate installer integrity; Windows Authenticode is still unsigned.

This is a public GitHub preview channel, not an app-store beta/testing track. No release watcher jobs are created. Each player uses their own local copy and credentials. Source is MIT licensed; no credentials or private player snapshots belong in the release.
