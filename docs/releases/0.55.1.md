# Backstage Forever 0.55.1 — Mac downloads

From Backstage Coding. Designed by Frank Arena.

**The Mac app is here.** 0.55.0 announced the Mac app, but its Mac downloads never got built. This release has them: `Backstage-Forever-0.55.1-macOS-arm64.zip` for Apple Silicon (M1 and later) and `-macOS-x64.zip` for Intel Macs. Unzip it and drag **Backstage Forever** into Applications.

**The first time you open it.** The app isn't signed with an Apple developer certificate, so macOS stops it the first time. Open it once, then go to **System Settings → Privacy & Security**, scroll down and click **Open Anyway**. If macOS says the app "is damaged", open Terminal and run `xattr -cr "/Applications/Backstage Forever.app"`, then open it again.

**What works on a Mac, and what doesn't:** see the [0.55.0 notes](0.55.0.md). In short, everything except the live link, the built-in free AI, reading steps aloud, starting the game from the app and automatic updates.

**Windows:** nothing changes for you in this release.
