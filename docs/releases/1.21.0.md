# Backstage Forever 1.21.0 — Upgrades in the in-game atlas

<!-- whats-new: stable -->

<!-- change: atlas-upgrade-marks | new | desktop,addon | atlas -->
- The in-game Instance Atlas (`/bf atlas`) marks each boss drop that is an upgrade for your character with a green "Upgrade", next to the gold "Wish" from your wish list. The banner of every dungeon says how many upgrades and wishes it holds, on its own line so long dungeon names stay readable.

<!-- change: atlas-upgrade-source | compatibility | desktop,addon | none -->
The desktop works out the upgrades by comparing each drop with what your character wore when the app last read its saved file, using the same rules as "Upgrade for you" on Dungeons & raids. It writes the list into the same small file as your wish list; the game reads it at your next login or `/reload`. After you equip new gear, `/reload` once so the desktop sees it, then once more to refresh the marks. Characters need a class set and a saved file from the installed game build. Not yet checked in the real game: the marks and the new banner line.
