# Backstage Forever 0.53.0 — German

From Backstage Coding. Designed by Frank Arena.

**Backstage Forever speaks German.** If your WoW is in German, the app and the addon's messages switch to German by themselves: page titles, buttons, notes, Help, the welcome tour, and the messages and pop-ups in game. Help → Field guide → **Language** lets you pick English or German yourself.

**Machine-translated, and marked.** The German was translated on this computer with a local AI model and spot-checked, using the German game's own words (Ruhestein, Flugmeister, Stufe, Lehrer). The menu says "maschinell übersetzt" while it's on. If something reads oddly, tell us through Help → Support, and the next version will carry the fix.

**What stays English.** Quest, item and NPC names come from our English quest data, so route steps and lists that are built from them stay in English for now, as do sentences that have numbers in the middle. More of the app and more languages will follow the same way.

**After updating:** quit WoW and start it again once, because this version adds a new addon file.
