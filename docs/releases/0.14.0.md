# Backstage Forever 0.14.0 — the companion goes live

From Backstage Coding. Designed by Frank Arena.

This preview makes the companion a real sidekick in two ways. The AI can now look things up while it answers, and an optional live game link lets the desktop know where you are right now, without a reload. **1.0 remains held for Frank's hands-on acceptance.**

## The AI looks things up instead of guessing

AI questions can call seven read-only local lookups over the same bundled, source-labelled Forever references the rest of the app uses:

- **find_npc**: where an NPC is, with direction and distance when they're on your map
- **search_quests** and **get_quest**: quest NPCs placed on the map, plus turn-ins ready now
- **find_item**: observed sources and vendors
- **plan_travel**: routes between places
- **get_character**: only when *Use my active character* is on
- **get_live_state**: your live game reading
- **quest_waypoint**: a `/bf guide` command you paste yourself

Ask "where is Cairne Bloodhoof?" and you get Thunder Bluff, around 59.9, 51.7, with the source and date. Ask for a quest walkthrough and every NPC is placed. Answers that used lookups are labelled and list what was checked.

The lookups cannot act in the game, reach the internet, read files or see notes, goals or memory. Each question allows at most 10 lookups. They work with the OpenAI, Anthropic and xAI APIs, Ollama and Ollama Cloud, the ChatGPT plan and the Claude subscription; the Claude subscription uses only an in-process lookup server, with no Claude Code tools. Larger models (about 27B and up, or cloud models) use the results most reliably.

## Optional live game link

Turn it on under **Settings → Game connection**, then type **/bf live on** once in WoW. The addon draws a tiny calibrated colour strip in the top-left corner of the game window. Backstage Forever reads only that strip, about twice a second, so the companion knows your live:

- zone and coordinates, and which way you face
- level, XP and free bag space
- target NPC
- tracked quest and which of its objectives are done
- mounted, resting and in-instance state

During combat the strip carries only an "in combat" flag. Values the client protects, such as health, are reported as unknown.

The link sends no input, reads no game memory or files, stores no screenshots and makes no network requests. The Companion panel shows **Live · Zone x, y**, and AI answers prefer the live position over the last saved snapshot. Stale readings are never presented as live. `/bf live status` prints an in-game diagnostic, and `/bf live off` stops the strip.

This was checked in the real Forever client on a 3440×1440 display. Position, facing, level, mount, XP, bags and tracked quest decoded live while flying from Thunder Bluff into the Barrens.

## Other changes

- The managed addon set is now **thirteen files** (adds `BackstageForeverLive.lua`) and a per-character `BackstageForeverLiveSettings`. Setup prepares, verifies and repairs it like the others.
- Quests ready to turn in now point the AI at the turn-in NPC. Places the travel reference doesn't cover are reported as uncovered instead of guessed.
- New release gates: `npm run test:companion-tools` and `npm run test:live-link`.
- App, lockfile, addon TOC and emitted capture metadata align at **0.14.0 preview**.

## Update

Installed previews receive 0.14.0 through the authenticated preview channel: **Updates → Check now**, then choose when to install. After updating, a voluntary `/reload` in WoW loads the new addon file. Use only the Windows setup executable from the [official release](https://github.com/farena-ai/Backstage-Forever/releases/tag/v0.14.0).

Not yet verified: live ChatGPT-plan, Claude-subscription and paid-API tool calls (tested with fixtures only), clean-machine installation, and Windows publisher signing. Check WoW Forever's policy on external screen-reading tools before relying on the live link. **1.0 stays held until Frank reviews the real experience.**
