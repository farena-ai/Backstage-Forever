# Backstage Forever 0.32.0 — a quiet live link

From Backstage Coding. Designed by Frank Arena.

**The live strip is now tiny.** The coloured strip the addon draws for the app shrinks from 456×12 to **84×4 pixels**, about a sixteenth of the space, and it still updates five times a second.
- **Calibrated colours:** four grey reference cells let the app read 4 shades per colour instead of 2, so the same information fits in far fewer cells.
- **Exact pixels:** each cell is exactly 2 screen pixels at any UI scale.
- **Your corner:** `/bf live pos topleft|topright|bottomleft|bottomright`. The app finds it in whichever corner you pick.
- **Quiet when idle:** after a few seconds of standing still it updates less often, and the app still knows the link is live.

**Playing over remote desktop?** If the link drops, type `/bf live safe` to switch back to the larger, sturdier strip; `/bf live compact` switches back. Settings → Game connection and the Now checklist show which mode and corner are in use.

**After updating:** type `/reload` in WoW once.
