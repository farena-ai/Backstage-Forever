# Backstage Forever 0.6.0

Forever quest references come to your character's plan: reported chain links, NPC locations, listed rewards and better evidence for the next useful step. Local guidance needs no AI account or database setup.

**[Download the Windows installer](https://github.com/farena-ai/Backstage-Forever/releases/download/v0.6.0/Backstage-Forever-0.6.0-Windows-x64-Setup.exe)** · [Beginner setup guide](../GETTING-STARTED.md)

## Get started

Install the Windows setup executable normally. BF prepares its updated addon for your connected game folder. If WoW is running, type `/reload` to load the updated addon, then reload again or log out to save its first new capture. BF imports that snapshot automatically. Open Adventure for the enriched plan or Quest Guide to inspect quests.

Quest Guide starts with your character's current quests. Search locally by name or quest ID, inspect chain status, separate guaranteed rewards from reward choices, and review the source build, collection date and report count. Where supported, Copy game waypoint prepares a short `/bf guide` command for you to paste into WoW. The addon checks it before placing a marker or printing coordinates. You remain in control of all movement and game actions.

## Automatic reference setup

The initial licensed pack is bundled for offline use. Compatible game snapshots enable exact-ID/build reference guidance; automatic checks refresh public whole-build data while BF is open. No character details are sent with those downloads. Automatic reference checks can be disabled, and local guidance continues without a provider. Full completed-quest ID sets remain local; explicitly submitted AI questions use only bounded approved reference facts when character sharing is enabled.

The initial pack contains 3,392 server-cache quest records and 1,187 positive reported next-quest links for live Forever build 1.60.1.70862, with smaller observed NPC and objective coverage. A cache record does not prove playability. Reported chain links do not establish all prerequisites. NPC positions are approximate interaction observations. BF shows missing conditions and build conflicts rather than substituting unrelated Classic or beta data. Read [coverage and provenance](../FOREVER-DATA.md).

Data from Efficient Games (https://efficient.games), licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), filtered and normalized by Backstage Coding. Application code remains MIT licensed.

## Update recovery

The updater now retries temporary connection failures up to three times, uses fresh partial files, preserves older verified installers, and gives clearer retry and Releases actions. Failed newer metadata no longer appears as “up to date.” Signature, repository/version binding, full SHA256 and size verification remain mandatory. Unsafe cache paths and failed partial cleanup stop the operation safely.

If your older BF finds 0.5.0 but cannot download it, download this release's Windows setup executable from the official release page, close BF, and install normally. Your profiles and encrypted connections remain in your Windows account's app-data folder. The old running copy needs a successful upgrade to receive the new updater code. See [recovery instructions](../UPDATES.md).

## Verification boundary

The release gates include unit, Lua, reference-data, real Electron setup/UI/autosave/integration/command-center/Quest Guide and packaged-resource checks. Measured acceptance is recorded in [Validation](../VALIDATION.md). Public data and synthetic fixtures do not certify every live quest, every Forever API, provider entitlement or completion of an installed self-upgrade. Desktop progress still comes from reload/logout snapshots.

The Windows installer has no Authenticode publisher certificate. App updates use separate pinned Ed25519 signature and installer integrity verification. No gameplay automation, forced reload, paid background inference, external service or scheduled release watcher is added.
