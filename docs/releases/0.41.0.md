# Backstage Forever 0.41.0 — quality of life helpers

From Backstage Coding. Designed by Frank Arena.

Four small helpers. Each one is off until you switch it on, so nothing changes unless you want it to. Type `/bf qol` in WoW to see them.

- **Coordinates** (`/bf qol coords on`): your map position, like "42.3, 67.8", just under the minimap.
- **Faster auto-loot** (`/bf qol loot on`): when the game is auto-looting anyway, everything is taken at once instead of one item at a time. Items that ask "bind on pickup?" still wait for you.
- **Dismount at flight masters** (`/bf qol dismount on`): when you open a flight master's map while mounted, you get off your mount so you can pick a flight. Never in combat.
- **Instant quest text** (`/bf qol questtext on`): quest text appears at once instead of fading in, using the game's own setting. Switching it off puts your old setting back.

None of them accepts or hands in quests, picks a flight for you or loots anything the game wouldn't.

**After updating:** quit WoW and start it again once, because this version adds a new addon file.
