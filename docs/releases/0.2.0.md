# Backstage Forever 0.2.0 — cinematic desktop and automatic updates

From Backstage Coding. Designed by Frank Arena.

Download the Windows x64 setup executable below, run it for your Windows account, then open your existing journal. **If you have 0.1.0, install this version manually once:** that earlier build has no updater.

- Original painted citadel scenery, embossed companion medallion, bronze/leather panels, parchment journal and bundled fantasy typography.
- Automatic authenticated update checks/downloads while the app is open. Install on normal exit by default, or choose Restart and update. Preferences and manual checks live in Updates. No forced game-session restart and no external scheduled watcher.
- Releases are authenticated by a pinned Ed25519 update key, exact version/repository binding and installer SHA256/size verification. The installer still lacks a Windows publisher certificate; app-update signatures and Windows Authenticode are separate.
- Existing local characters, notes, goals, provider connections and privacy defaults are preserved.

**Validation:** 62 automated tests passed locally, plus real Electron GUI, native storage/reset integration, packaged startup and production-key manifest verification. Wide and compact layouts were inspected. The tag-triggered Windows workflow independently tests/builds/signs this release before publication.

**Remaining:** actual installed old-to-new self-upgrade/clean-machine acceptance, live ChatGPT/Claude account acceptance, safe Grok subscription inference, account-aware model discovery and verified addon-data import. Grok OAuth exists; inference isolation remains the blocker. The addon is still an experimental template, not certified in-game integration.

Each friend installs independently and uses their own account. No credentials, private signing material or shared backend are bundled. See README, docs/UPDATES.md and docs/ROADMAP.md in the source archive.
