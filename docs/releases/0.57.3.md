# Backstage Forever 0.57.3 — One /reload after an update

From Backstage Coding. Designed by Frank Arena.

**One /reload is enough.** After an update, the "Type /reload in WoW" banner on Now used to need two reloads before it went away. Now one does it.

Why it took two: when you /reload, the game saves using the addon that was running, still the old one, so the first save after an update named the old version. The app now looks at when the game wrote the save. A save written after the update arrived means the game has reloaded and the new addon is running.

**After updating:** type `/reload` in WoW once.
